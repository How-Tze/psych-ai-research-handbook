从聊天开始，认识做研究会用到的 AI 工具

v1.3 · 2026-10-16

作者

Hao Xie

你打开常用的 AI 应用，在输入框里写一句话，等它回答。接下来要读论文，可以把原文交给它；要处理表格，需要确认它能否读取表格、实际计算并交回文件。想完成的事不同，要用到的功能也不同。

本章帮助你认出这些功能和它们所在的产品，并选择一个适合当前任务的起点。后文说的“工作环境”，就是你通过什么应用使用 AI、它这次能看哪些材料、能做哪些操作。从手机上的聊天应用开始，也能逐步尝试这些用法。

先把熟悉的聊天，用得更深入一点

如果你目前主要用 AI 翻译和改写，可以先试着改变一次对话的任务。例如，在 DeepSeek 中，把“解释一下相关与因果”改成：

我在学研究方法。请给我一个“两个变量有关联，但不能据此确定因果方向”的短例子。先让我说出理由，再根据我的回答追问，最后换一个例子让我自己判断。

你发给 AI 的问题、要求和补充材料，常被统称为提示词。用普通中文说清任务就可以。在同一段对话里补充背景、指出哪句话没懂，也是在改进提示。

再比如，提供自己已经读过的一段论文，请它列出两种可能解释，说明什么观察有助于区分。读完回答后，指出你认为说不通的地方，再让它结合原文重新比较。一次对话由此可以逐步深入到你真正关心的问题。

你可能会遇到哪些产品

先按手头任务认识几类常见工具。它们的功能有重叠，同一个产品也可能同时支持聊天、搜索、文件分析和连续执行。

你希望做什么 具体产品与功能 研究中的一个用法
用自然语言来回讨论问题 千问、DeepSeek、豆包、ChatGPT、Claude、Gemini 解释一个概念，比较两种说法，再根据你的回答追问
围绕指定资料阅读和提问 Google 的 Gemini Notebook（较早教程中常见 NotebookLM） 放入论文，在回答中查看对应原文；把几篇材料中的定义或任务放在一起比较
处理上传的表格，形成可查看的文件 千问办公、ChatGPT 的文件处理与 Work 功能 说明整理要求，获得一份新表，再打开检查
读取项目文件、修改程序并实际执行 Qwen Code、Codex、Claude Code 按已经确定的规则处理数据，运行程序，保存结果，并处理运行中出现的问题

“千问办公”是面向文件和办公任务的产品，Qwen Code 则是代码助手；它们与日常聊天使用的千问有不同的入口。选工具时，先找当前任务需要的功能，再看自己账号中是否可用。账号、地区和版本会影响使用范围，开通与选择可查动态指南。本章产品资料核查于 2026-10-16，官方来源列在章末。

“让 AI 读论文”，具体是怎样发生的

你平时下载的论文通常是 PDF 文件。在千问办公等支持上传资料的工具中，可以把允许使用的全文放进对话，再提出与原文有关的问题；普通聊天也可以先复制一小段文字。AI 得到的材料不同，能回答的问题也会不同。

例如，只有摘要时，可以讨论研究大致在问什么；要比较两篇论文实际用了什么任务，就需要方法部分。支持资料引用的工具还会提供原文位置，方便你点回去读上下文。引用入口提供了回查的路，是否概括正确仍要结合原文判断。

从自己的问题出发，可以这样试：

请根据我提供的两篇论文，分别说明参与者做了什么、研究者记录了什么。每一项注明来自哪篇论文的哪个部分。最后指出一个值得我继续精读的差别。

如果你还没有找到论文，则需要搜索。让 AI 联网查找资料，与让它阅读你给出的文件，是两件不同的事。有些产品把多轮搜索、阅读来源和整理报告的功能称为“深度研究”。得到一份带链接的报告后，你仍要选择值得读的原文；本书的文献探索章会教你怎样作这种选择。

“让 AI 做分析”，为什么会出现代码

假设你的数据在 Excel 表里，每一行是一条参与者记录，每一列是一道题。要计算量表得分，可以手动使用公式，也可以把步骤写成计算机能执行的指令。后一种指令就是代码；把一组指令保存成可反复运行的程序文件，常称为脚本。Python 和 R 是科研中常见的编程语言名称，类似于告诉你这份程序用哪种语言写成。

你可以用中文说明“哪一道题反向、缺几题时不计分、结果保存成什么表”，让 AI 协助写出相应代码。然后有两种情况：它只把代码显示给你，或者它还具备执行工具，能实际运行并交回结果。只有第二种情况完成了计算；第一种还需要有人或其他工具执行。

因此，先看清自己需要的是解释、程序，还是计算后的文件。若已经用熟 SPSS 或其他统计软件，也可以让 AI 帮你理解操作和语法，再在熟悉的软件里完成。

数据分析章提供已运行的教学材料。没有编程经验时，可以先读表和解释，再尝试让 AI 协助运行一个小例子。每走一步，都把自己的要求与对应的计算步骤对照起来，逐步弄懂它实际做了什么。

同一个应用，为什么还有“模型”可以选

千问、DeepSeek、ChatGPT 这些名字可以指你打开的应用。应用背后负责理解问题、生成内容的核心系统，叫作 AI 模型。例如，ChatGPT 是产品名称，GPT 是模型系列名称。不同模型或不同设置，处理问题的方式与表现可能不同。这里的“模型”与统计课里的回归模型不是同一个意思。

选用产品时，你还在选择它提供的功能：是否能读附件、搜索网页、执行程序、保存文件。这些操作能力通常统称为工具。所以，即使某个模型能写出一段分析代码，也不能由此推断当前聊天窗口已经具备运行它的条件。

初次使用时，先确认能否完成自己的小任务。以后遇到更复杂的问题，再用同一份材料比较不同模型的回答，看看哪一个更有帮助。

“项目工作区”就是把同一项研究的材料放在一起

如果围绕同一个课题反复讨论，每次都重新上传背景、解释变量，会很费力。有些应用提供“项目”或类似功能，用来集中相关对话、文件和说明。你可以把它理解为应用里为这个课题准备的工作位置。ChatGPT 的官方说明就把相关聊天、文件和要求放在项目里作为一种持续工作的用法，具体设置见指南的项目工作区教程。

例如，把课题说明、当前论文和结果表放在一起，并写明“这次用修正后的结果表，旧表只供比较”。下一次就从这些材料开始。没有专门的项目功能，也可以在自己的文件夹里保存同样的说明，每次提供需要的部分。

保存着文件、当前对话能访问它、AI 已经读过它，是不同的事情。开始任务时让它说明读到了什么，缺的材料再补给它。这样你不会因为“文件上周传过”就误以为它今天也在使用。

“Agent”怎样从聊天中多走几步

你可能见过“智能体”或 Agent 这个名称。先看一个具体过程：你要求更新一份报告，AI 读取项目说明，找到结果表，运行已有程序，检查新文件，再根据结果决定是否还要修改正文。你交代的是一项要完成的工作，它在允许范围内根据中间情况继续行动。

Qwen Code、Codex、Claude Code 都可以读取文件、修改代码、执行命令。DeepSeek 也提供了 DeepSeek Harness，能够处理文件、运行脚本和持续修改成果，目前为预览版。比如，你可以先让它读取文件夹里的分析说明，再运行已有程序，最后打开生成的表格核对。选择这类工具时，要看它能访问哪些文件、执行哪些操作，以及会在什么情况下等你确认。

同一个应用也可能兼有聊天与连续执行功能。实际研究中，可以先用聊天讨论方案，再把确定的任务交给能执行的工具。问题、方法和解释由你判断；工具则把相关操作完成到你可以打开和检查的成果。

至于多个 Agent 怎样分工、怎样保存可复用的做法，等出现重复任务时，再读第10章。

注记如果遇到 Harness、API、Skill，可以先这样认

Harness（运行框架）常见于技术文章，指把模型、工具、材料和执行规则组织起来的程序部分。它负责让模型调用工具、接收结果并继续执行；你使用的应用还会提供对话界面、文件预览等功能。

API是软件调用服务的接口。平时是你在对话框里发送问题；使用 API 时，可以由程序按安排把一批任务逐次发给 AI。它通常需要另外的设置和费用管理，普通聊天练习不需要先学它。

Skill（技能）可以把一类任务的说明、示例和所需材料保存起来，供支持它的 AI 工具调用。例如，你反复使用的一套文稿检查方法，可以整理成可复用的技能。它的具体样子会在重复工作章说明。

今天就从一个小任务开始

先选择已经能使用的聊天应用，打开第一次完整任务，把那张小表和说明复制进去，请 AI 复述内容并起草一段文字。这个练习不依赖文件上传，也不需要运行程序。

以后要处理自己的文件时，再按需要多走一步：选择允许用于该工具的材料，提供一个容易核对的片段，让它说明读到了什么；需要实际计算，就要求给出执行结果；需要新文件，就打开看看内容。扫描 PDF、复杂表格如果读错了，可以换成清楚的页面或片段重新试。

任务结束后，把采用的成果和下一步保存到自己找得到的位置。现在，你已经可以开始一次完整协作；遇到新任务，再回来选择需要增加的功能。
