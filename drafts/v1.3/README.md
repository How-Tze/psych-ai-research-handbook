## 本次编辑判断

上一轮稿件的主要问题是叙述重心与语气：方法章按统计概念展开，AI 对话退到辅助位置；其他章节也较多使用“能力目标、产物、约束”等写作任务语言。此次保留解释深度，改为从读者遇到的问题出发，说明如何提问、如何理解回答、接着怎样做。示范问法放在需要它的地方，避免把每节都写成固定提示词模板。

采用 [Humanizer-zh 的编辑规则](https://github.com/op7418/Humanizer-zh/blob/main/SKILL.md)，重点检查翻译腔、抽象名词堆积和重复表达，保留术语、数字、引用与限定。它是表达编辑的参考，不是科学证据或“检测通过”的标准。未全局安装外部技能，也未执行其仓库代码。后续章节沿用[写作包中的中文编辑要求](../../briefs/v1.3-authoring-package.md#中文表达与全书扩写要求2026-10-14)。

方法章保留小例子的可手算性，明确六行的时间混杂，另用交互题检查是否能迁移。理论章用两个限定版本比较，不把现实机制假装成互斥二选一，不宣称AI提出新理论。分析章只深入随机截距这一种纵向起点，另说明何时需要随机斜率、时间与缺失扩展，不堆积高级方法名称。

原四章沿用部分压力—睡眠情境：方法章示范学习，理论章比较解释，分析章拟合模型，写作章从同一份输出形成段落。这组数据、假想结果与访谈均为教学构造。新文献章改用三篇真实的背景音乐论文，研究设计章则采用相邻但不同的背景谈话问题；没有把前者当成后者的实验证据。AI 问答、短文题目与试做反馈为教学编写，没有 AI 学习收益的实证承诺。

本轮特别保留两个完整判断过程：文献中“器乐曲优于有歌词音乐”为什么不能替换成“器乐曲优于无额外音乐”；设计中“每种条件四篇”为什么仍可能让文章与条件混在一起。方法说明放在理解这些问题所需的位置，不另开一套统计或实验设计教材。

## 同批提交的明确纠错

原 chapters/11-safety-recovery.qmd 最后“风险三问”的第三问为“出错后能完整恢复吗”，当前“任一是即升级”的写法方向错误。随本包审阅以下替换稿，未写入正式章：

> 任务很小且明显可逆时，先问三句：它会进入正式证据吗？会改变方法或伦理吗？出错后能完整恢复吗？前两问回答“是”或“不确定”，或第三问回答“否”或“不确定”时，需要进一步判断错误后果，并配置相应的验证、人工确认和恢复措施。
