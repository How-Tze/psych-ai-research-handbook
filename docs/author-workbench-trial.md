# 私人作者工作台：本地试用交付

2026-10-18，工具版本 0.1.0，TASK-016 进入 REVIEW。两站正式版本不变。

## 作者从哪里开始

桌面和开始菜单均已安装 **心理学 AI 手册·作者工作台**。无需终端，打开后恢复上次阅读位置。首次准备每个项目的阅读副本约需等待一分钟，之后复用缓存；生成新草稿预览会重新渲染该项目。

从正文点选一段，或点顶部 **选段改字**，在右侧修改。看到 **已保存到本机** 后即可离开。正文片段之外的改进，用 **留批注**、**本章改进** 或 **记个想法**。从 **设置快捷入口** 可取用阅读页书签；**从页面地址打开** 提供网址粘贴入口。

完整操作、数据位置、备份恢复、安装卸载和下一轮 Agent 命令见[使用说明](../tools/author-workbench/README.md)。

## 试用边界

- 段落编辑保留 Markdown 标记；图片与图注、表格、公式、代码、标题及跨段结构调整使用批注。这版不是完整的富文本排版器。
- 正文点击入口已实现；本次自动浏览器无法对跨域 iframe 执行点击，所以浏览器实测使用同页的 **选段改字**。实际使用时可同时体验点选入口。
- 已验证服务关闭后启动、保存后重开和一致备份恢复；未重启用户的 Windows、未模拟整机断电，也未逐一测试所有浏览器的书签跳转提示。
- 本地协议已经注册并实际启动；公开网站仍没有新增“作者模式”按钮。AW-07 需要单独批准。
- 测试只使用隔离资料库，真实意见箱交付时为零条。不会后台调用模型；“已整合”表示进入候选源码，不表示发布。

## 后续维护

先根据作者试用反馈修复入口、编辑手感和保存提示。不要为了试用顺手修改正文。开始新的内容迭代时，按使用说明读取私人待办、冻结本轮修订、保留作者改字，再处理批注并回填证据。

重复段落须通过上下文和快照定位；不能因另一个同名段落变成唯一剩余项就自动替换。渲染标记必须测试图片说明、勾选列表及复杂区块。保存事务成功与备份失败分开报告；Windows 备份与恢复必须先关闭 SQLite 文件句柄。这些实现经验保留在工具测试中，不扩充为新的出版治理层。

临时日志、截图、测试数据库、模拟副本和本地打包产物留在忽略目录。正式 main、标签、历史资产和线上两站均未修改；未推送、合并或部署。
