# 在数字稿之后补写解释

本段由作者为教学编写，使用 [第二轮数字稿](round-2/results.md)中的实际合成计算，不是脚本自动作出的科学判断。

> 两种计分完整性规则下，压力和反刍系数都为正，但大小变化较明显。比较规则同时改变了纳入记录，因此这里比较的是两套处理方案得到的结果，不能把差异全部归给一个孤立的统计因素。报告保留主规则及比较结果，并说明系数大小对这一处理选择较为敏感。由于数据和题目均为教学构造，这些数字不用于支持现实人群中的机制或因果结论。

检查时要分开看：系数和记录数回到结果表；规则含义回到分析规格；“怎样解释变化”由研究者结合设计与方法判断。若迁移到真实研究，保持主规则还需要独立的计分和缺失处理依据，不能只引用“先前定过”。
