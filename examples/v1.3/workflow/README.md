# 从一次写作到下一次工作：教学项目入口

2026-10-16。全部研究数据为既有合成教学数据；工作次序、组会决定和交接情境由作者编写。两份数字稿由配套脚本实际生成，不能称为真实研究发现或 Agent 实测。

## 当前要完成什么

用已计算的问卷结果，练习写清主分析和比较分析，再把数字描述与研究者的解释分别保存。主规则地位来自本教学规格，不代表对真实量表的推荐；不依据系数大小重新选择主规则。

## 本例的决定与下一步

模拟决定：最终候选同时保留两种规则的结果；相同方向不足以说明系数稳定，不写成“已经证明机制”或“结果完全稳健”。第一轮仅作过程示例，当前阅读从第二轮数字稿和人工解释候选开始。

已完成：两轮数字稿生成、数字与输入表核对；稿件仍是教学候选。待做：把这一做法迁移到自己的研究时，重新审查计分、缺失、模型和报告依据，不能照抄本例主规则。若当前只编辑本教学稿，下一步是比较数字段与解释段各自说了什么，而非更换分析规则。

下次启动可这样问 AI：请先读本页、确认结果表和第二轮数字稿，复述当前要继续的工作，并区分已确认的数值与仍需研究者判断的解释。发现输入不可访问或版本不一致时，指出具体缺项。

## 想自己运行两轮

下载教学目录并保留相对位置后，在本目录运行以下命令。需要 Python 3.10 或以上；也可以直接阅读已生成文件，不必先配置环境。

```text
python build_report.py --source ../reference/survey-sensitivity.csv --mode main --output my-run/round-1.md
python build_report.py --source ../reference/survey-sensitivity.csv --mode compare --output my-run/round-2.md
```

脚本要求本例约定的字段及两种规则同时存在，拒绝重复规则、缺失字段和非有限系数，且不覆盖已有输出。它并不验证输入表是否来自正确模型。文件指纹用于识别实际读取的字节，换行符变化也会改变指纹；指纹相同不证明方法有效。

这里 `main` 与 `compare` 只改变报告中呈现哪些行；分析本身仍来自原运行包。若数据或分析规则发生实质变化，应先在明确的分析规格下重新运行分析、检查结果，再生成新报告。不要修改确认结果表以“试出”喜欢的文字。
